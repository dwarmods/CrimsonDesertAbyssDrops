# Vanilla drop tables

Each subdirectory holds the unmodified Crimson Desert `dropsetinfo` body and header for that game version, used as the input to `tools/build.py`.

These files are copyright Pearl Abyss. They are in this repository only so the overlays can be rebuilt in CI. Each public release already ships the full table with 35 drop sets patched, so including the vanilla original does not add new game data. Do not use them for anything other than rebuilding this mod.
